# SubGreek Studio

Τοπική εφαρμογή React για μετάφραση SRT μέσω αντιγραφής/επικόλλησης στο Google AI Studio Chat. Δεν καλεί API.

## Εκκίνηση

Node.js 24 και npm:

```powershell
npm install
npm run dev
```

Ανοίξτε http://127.0.0.1:3000. Χρησιμοποιήστε σταθερά την ίδια διεύθυνση/θύρα και browser για την αποθηκευμένη εργασία.

## Χρήση

1. Φορτώστε το αρχικό αγγλικό SRT. Μη έγκυροι χρόνοι ή διπλά αναγνωριστικά απορρίπτονται.
2. Στο Βήμα 2 επιλέξτε **Ολόκληρο το αρχείο — ένα prompt** (προεπιλογή νέας εργασίας) και αντιγράψτε το prompt στο AI Studio. Προαιρετικά επιλέξτε 50, 100 ή 150 υπότιτλους ανά μέρος. Οι υπάρχουσες εργασίες διατηρούν την επιλογή τους. Σε μεγάλα αρχεία η απάντηση του chat μπορεί να κοπεί: μη έγκυρο JSON απορρίπτεται, ενώ πλήρες JSON που παραλείπει εγγραφές εισάγεται με αναφορά ελλείψεων. Μετά την εφαρμογή, ζητήστε **Prompt διόρθωσης / ελλείψεων** για τις εκκρεμότητες.
3. Επικολλήστε ολόκληρο το JSON με `requestId` και `translations`. Πατήστε **Έλεγχος απάντησης**, διαβάστε την προεπισκόπηση και **Εφαρμογή**. Το `requestId` συνδέει την απάντηση με την πηγή και τα ζητούμενα ID, δεν είναι μηχανισμός πιστοποίησης γλωσσικής ποιότητας.
4. Για διορθώσεις επιλέξτε **Prompt διόρθωσης / ελλείψεων**. Για ενημέρωση ήδη μεταφρασμένων εγγραφών ενεργοποιήστε ρητά την αντικατάσταση στην εισαγωγή.
5. Ελέγξτε στον Editor. Οι προειδοποιήσεις αφορούν μήκος, γραμμές, ταχύτητα ανάγνωσης, ύποπτα αλφάβητα και αντιστοίχιση παλιού SRT.
6. Εξαγωγή SRT/VTT/δίγλωσσου. Αν υπάρχουν εκκρεμότητες, το προτεινόμενο όνομα περιλαμβάνει `_DRAFT`. Οι κενές μεταφράσεις εξάγονται ως `[Χωρίς μετάφραση]`, χωρίς απώλεια εγγραφών.

Η πρόοδος και η επικολλημένη απάντηση αποθηκεύονται στο localStorage. Αν η αποθήκευση αποτύχει εμφανίζεται μήνυμα. **Λήψη εργασίας** δημιουργεί ανεξάρτητο `.subgreek.json` και **Φόρτωση εργασίας** το επαναφέρει. Το βίντεο επιλέγεται ξανά μετά από ανανέωση.

## Ανάκτηση παλιού ελληνικού SRT

Φορτώστε πρώτα το αγγλικό και έπειτα το ελληνικό στο Βήμα 3. Προτείνονται μόνο μοναδικά ζεύγη με ακριβώς ίδιους αρχικούς χρόνους, χωρίς αντιστοίχιση βάσει θέσης ή αυθαίρετη διόρθωση χρόνων. Όλες οι ανακτημένες εγγραφές απαιτούν έλεγχο νοήματος. Οι υπόλοιπες παραμένουν στην αναφορά και στο αρχικό κείμενο της απάντησης.

Εναλλακτικά, δημιουργία αρχείου εργασίας και αναφοράς χωρίς μεταβολή των αρχικών:

```powershell
npx tsx scripts/recover.ts "original.srt" "translated.srt" "artifacts/recovery"
```

## Έλεγχοι

```powershell
npm test
npm run lint
npm run build
```

Προαιρετική δοκιμή με τα πραγματικά GMA SRT (δεν περιλαμβάνονται στα tests):

```powershell
$env:SRT_TEST_ORIGINAL = 'C:\path\original.srt'
$env:SRT_TEST_TRANSLATED = 'C:\path\translated.srt'
npm test
```

Ο τεχνικός έλεγχος δεν πιστοποιεί τη μετάφραση ούτε τον συγχρονισμό με τον ήχο. Οι χρόνοι της πηγής είναι η βάση αναφοράς.
